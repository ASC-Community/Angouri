# Notes and puzzle hints

**Notes** is the book-icon reference for remembering mathematical relationships. It uses independent inputs, reusable identities and before/after comparisons. It leads with the current concept, keeps previous numbered concepts visible, and hides future concepts even inside inactive comparison panels. It contains no authored target overlays, fitted current-puzzle subgoals, solution-order instructions or complete current-puzzle constructions.

**Hints** is the separate light-bulb entry for the current authored puzzle. Its broad clue and Notes/view links come before **Another hint**. The second clue then offers **Show a sketch** for explicit puzzle-specific help. Both disclosures have keyboard-operable triangles and expanded-state semantics. Worked or targeted diagrams load only when requested, omit duplicate earlier-reference sections, and cannot mutate the active recipe or reference context. Challenge sketches retain unresolved decisions rather than spelling out the final full recipe.

Only Hints receives the yellow invitation after stalled rearrangements. Opening Notes does not dismiss it; opening Hints or solving does. Neither entry appears on 1.1-1.2. Create and shared challenges have the complete Notes reference without authored Hints.

The diagrams are isolated, kernel-evaluated examples. They do not insert blocks, change the player's recipe or history, award completion, or move the player's inspection position. A comparison with buttons keeps every choice on the same mathematical plot scale. The earlier curve is dashed and the selected curve is solid; exact readings at named positions explain the difference rather than asking the player to judge small visual offsets. These are comparisons to inspect, not decorative animations or a second evaluator.

Notes include the current lesson and its prerequisites even when the player has completed later puzzles. Completion history never reveals later material on an earlier replay. Create, shared challenges and the optional More shape puzzles collection have the complete reference because they have no authored lesson order. Their examples remain isolated from the active construction.

The complete 1.5 lesson stays in the Height tab of later puzzles, including its Equation/Flow buttons, signed-gap guidance and fractional-lift examples. Returning to 1.5 or reloading it restores the same lesson; returning to 1.4 or earlier still withholds the later concept. Puzzle-specific gap-first planning is in Hints. Height-gap tracking remains available in every authored polynomial puzzle from 1.3 onward, so later references must not drop these instructions simply because the chapter changed. Equation and Flow explicitly name the positions of the lowest and highest required targets, comparing the same fixed pair throughout edits. Ties use the first (leftmost) target. This selects extrema among the required target samples, without estimating extrema between them. Puzzle 3.5 compares height at x=1 minus height at x=4 using evaluation-bar notation, whose required gap is `9/8`; the current recipe's difference remains signed.

Chapter tabs are restricted as well as their content. Shape notes first appear in the normal interface at 1.3; the first two puzzles use simple block choices. Within the reference content, lifting is absent from 1.1 and order comparisons are absent until 1.3. References, diagrams, operation badges, comparison choices and exact readings all follow the same boundary. The first two content boundaries remain defined for reference reuse, but there is no full-controls override to expose notes in those puzzles.
